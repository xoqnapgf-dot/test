# test

Playground for new-model experiments: animation, real-time music videos, web design.
Every project is a self-contained folder **named after its content**, with its own
`index.html` and relative paths, so it runs from disk or from any static host
(conventions in [`CLAUDE.md`](CLAUDE.md)).

| Project | What it is |
| --- | --- |
| [`kaminare-pv/`](kaminare-pv/) | **カミナレ** — a 3-minute real-time music video (WebGL, sumi ink, stained glass, thunder). Open `kaminare-pv/index.html`. |
| [`destruction-energy-explainer/`](destruction-energy-explainer/) | **破坏的账本** — a 7′50″ narrated real-time explainer on materials and destruction energy (strength, fragmentation, phase change, binding energy, flux), with 3D fracture, procedural materials and word-cued charts. Open `destruction-energy-explainer/index.html`. |
| [`bandori-review-vol1/`](bandori-review-vol1/) | **邦多利角色个人向点评 · 上** — a 5′12″ vertical (9:16) character-review video voiced by an open-source 曼波 TTS, with per-character cued motion graphics, official card art and stamps, ducked BGM and 《前へススメ!》 cut to the narration. Open `bandori-review-vol1/index.html`. |
