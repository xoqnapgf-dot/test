## English

Playground for new-model experiments: animation, real-time music videos, web design.
Every project is a self-contained folder **named after its content**, with its own
`index.html` and relative paths, so it runs from disk or from any static host
(conventions in [`CLAUDE.md`](CLAUDE.md)).

Each project is a fresh test: it is built from scratch, without reading earlier projects, unless the user asks otherwise (see `CLAUDE.md`).

## 日本語

新しいモデルを試すための遊び場です。アニメーション、リアルタイム・ミュージックビデオ、ウェブデザインを扱います。
各プロジェクトは **内容にちなんだ名前のフォルダ** で完結しており、それぞれ `index.html` と相対パスだけを持つため、
ディスクからでも任意の静的ホスティングからでも動きます（規約は [`CLAUDE.md`](CLAUDE.md) を参照）。

各プロジェクトは毎回まっさらな実験です。ユーザーが求めない限り、過去のプロジェクトは読まずにゼロから作ります（`CLAUDE.md` 参照）。
