# 六面星图 · AI 立方体

一个可离线运行的 3D 魔方互动小世界。六个面各有 9 枚独立能力贴片；六个固定的小世界持续把各自当前九格的组合转译成地景、路线与居民行为。

## 运行

- **免安装：** 双击本目录的 `index.html`，或用浏览器打开它。页面只引用相对路径；渲染脚本、样式、几何图案都在本项目内，无 CDN、外链字体、远程贴图或运行时 API 请求。
- **静态托管：** 将整个 `ai-constellation-cube/` 文件夹作为静态站点根目录发布；不需要 Node 服务端。勿只上传 `index.html`。
- **修改源码后重建：** 安装 Node.js 22 或兼容版本，运行 `npm install` 后运行 `npm run build`。构建会将 Three.js 与应用源代码打成根目录下的 `app.bundle.js` 经典脚本；预构建文件已随项目提供。
- **测试：** `npm test` 运行纯逻辑单元测试；`npm run build` 检查浏览器 bundle 可构建。

## 操作

- 在魔方外的空白区域拖动：旋转观察视角。
- 从魔方贴片上拖动：扭动相应切层，松手后吸附到 90° 格点。
- 鼠标滚轮或手机双指：缩放。
- 角落的回旋图标：缓慢还原到起始状态。

页面本身没有标题栏、状态栏、音量控制、帮助面板或品牌文字；只保留低调的角落操作提示与还原入口。
