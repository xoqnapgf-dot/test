# 设计与机制说明

## 1. 这是什么

**六面星图**是一件可操作的 3D 小型生态装置：中心是一枚真正由 cubie 组成、可扭层的 3×3×3 魔方；它周围有六个各自运作的微型世界。每面九枚贴片各自代表一项独立的模拟能力，总计 54 项。

这不是模型比较器，也不是 AI 接口演示。页面完全在本地运行，没有模型推理、网络请求、用户数据上传、真实 API 能力或随版本变化的模型测量结果。品牌名只在本说明书中使用；游戏场景只用原创色彩、形状与符号，不重画官方商标。

## 2. 操作方式

| 输入 | 结果 |
| --- | --- |
| 在魔方外的空白处单指/鼠标拖动 | 轨道式旋转观察角度，不改变方块状态 |
| 从魔方表面开始拖动 | 依命中贴片与拖动切向选择切层；拖动角度直接驱动层组，松手后吸附到最近的 90° 格点 |
| 鼠标滚轮 / 触屏双指 | 缩放镜头，不改动魔方状态 |
| 右下角回旋图标 | 取消自动队列，反向播放当前未还原的合法转动，返回初始排列 |

“按在方块表面拖动”与“从外部空白拖动”分别走两套输入状态；两者不会因为手指移动方向相似而混为一谈。触屏使用 Pointer Events 与 `touch-action: none`，不要求悬停、右键或键盘。

## 3. 六面与 54 项能力

每项能力有稳定 ID、专属图形贴片、六维属性向量与一个本地模拟规则。六维属性为：推演、感知、执行、记忆、连接、适配。向量只用于生成游戏内部的组合结果，不对应厂商指标。

### OpenAI / GPT 面：任务中继

1. **意图拆解**——将目标分成先后步骤，为中继路线提供顺序。
2. **代码构筑**——把抽象步骤转为可拼接的结构件。
3. **工具编排**——让相邻节点形成可切换的工具路径。
4. **视觉定位**——以感知节点对准世界中的目标构件。
5. **语音往返**——用有节律的信号标记输入与响应的往返。
6. **长文记忆**——拉长信息栈，使远端格点仍可连通。
7. **格式约束**——把散开的输出收进稳定的格框。
8. **资料汇总**——将多个来源汇入共享中继站。
9. **创意变体**——为已经成形的路线生成分支而非重复副本。

**整体机制：任务中继。** 推演、执行、连接属性共同决定 3×3 格点之间的接力网络；居民会沿当前最连通的路径前往工作站。连接强弱始终限制在固定范围，不会因单格变化变成无限分叉。

### Anthropic / Claude 面：编辑织架

1. **长卷压缩**——把较长输入折叠成仍可追踪的层次。
2. **条件守恒**——保持设定边界，减少织架中的断口。
3. **代码修整**——连接旧结构与较清晰的新结构。
4. **界面代办**——让居民沿界面格点完成逐步操作。
5. **不确定标注**——未能连接的节点会保留空隙，而不是伪装成完整结论。
6. **跨语写作**——在不同语言纹理之间搭建平顺过渡。
7. **会话续接**——跨段延续前文的路径与上下文。
8. **安全分流**——将高风险路线引导至较缓和的支路。
9. **图文互读**——把文字与视觉线索并排织入同一图案。

**整体机制：编辑织架。** 记忆、约束与审慎属性决定织架的连贯度；居民成对访问相邻节点。属性不匹配时结构会变疏，但不会随机坍塌。

### Google / Gemini 面：感知天文台

1. **多模态融合**——把不同感知输入汇合至共同观测点。
2. **检索锚定**——把外部资料连接到可回看的基座。
3. **实时转写**——让声波节律成为短距离信号。
4. **协作空间**——把共享文档类任务接入共同工作区。
5. **符号求解**——按结构化符号路径推进问题。
6. **视频时序**——跟踪连续画格之间的先后关系。
7. **地理关联**——把地点线索接到方向与地图路径。
8. **端侧感知**——以较轻的节点完成近身观测。
9. **并行代理**——让多个观察支路汇合到主观测台。

**整体机制：感知天文台。** 感知与连接权重决定镜筒和双环的对齐程度；居民轮流访问观测台。环结构采用有限角度、有限速度旋转，稳定表达信息融合而非“能量爆发”。

### DeepSeek 面：窄流计算

1. **专家路由**——按输入侧重点将任务送入对应支路。
2. **递进推演**——让推演路径逐步展开，而非一次跳跃。
3. **程序合成**——把计算流程组合成可复用的代码构件。
4. **数值演算**——依序处理有限数值节点。
5. **超长规划**——维持跨多段的任务路径。
6. **中英切换**——在两种文本通道之间切换。
7. **离线部署**——将一部分结构放在本地节点运行。
8. **算力配额**——将资源开销压入有限通道。
9. **自检回退**——发现断路时沿已知路径退回上一步。

**整体机制：窄流计算。** 推演与效率权重改变水道宽窄；居民倾向选择当前成本较低的路线。路径宽度和行进速度有上下限，避免“低成本”被误写成免费或无限算力。

### Alibaba / Qwen 面：模块集市

1. **权重改造**——把模块替换成适配当前场景的形态。
2. **语音图像协同**——让听觉与视觉节点互相传递线索。
3. **多语切换**——为不同语种居民保留互通道路。
4. **函数调度**——将请求送往合适的工具入口。
5. **长文索引**——为远处的长文本片段建立定位点。
6. **表格抽取**——把表格结构分解为可接驳的小格。
7. **界面构想**——从视觉布局生成可操作的界面模型。
8. **尺寸伸缩**——把同一能力缩放成不同规格的模块。
9. **行业适配**——让模块按垂直场景组合，而不是使用唯一模板。

**整体机制：模块集市。** 适配与连接权重控制模块增建及跨区桥接；居民在兼容的摊位之间交换。模块数量固定且尺寸有界，不会无限扩建。

### Z.ai / GLM 面：工程工坊

1. **终端编码**——由命令节点接入工程作业台。
2. **跨程记忆**——保留长任务各阶段之间的状态连接。
3. **请求节流**——用有限队列均衡突发请求。
4. **视频语义**——从连续画面线索中抽取结构关系。
5. **因果梳理**——按条件依赖顺序排列构件。
6. **缓存复用**——让已稳定节点减少重复处理。
7. **API 签名**——为函数入口建立明确的调用接口。
8. **本地托管**——将任务安排到自有运行空间。
9. **工作流回环**——检查输出并将结果送回下一阶段。

**整体机制：工程工坊。** 执行、记忆与推演属性组合成工字桁架和闭环工序；居民循固定工段前进，回到起点继续处理新任务。回环长度、桁架高度与队列容量均有限。

> 上述 54 项是场景与交互设计的能力隐喻，不是对某家公司的完整产品清单、模型规格或优劣评分。行业能力发布变化后可调整说明，但游戏内模拟仍不连接真实模型。

## 4. 魔方与能力贴片如何工作

- 魔方由 27 个 cubie 组成；每个外露贴片有唯一能力 ID，六面各 9 枚，共 54 枚。
- 能力贴片跟随所属 cubie 与外法线旋转，不是依面染色的 54 个重复图案。
- 每个品牌面中心有一个稳定的身份锚片。转动中层时中心锚片可迁移到另一侧；世界身份仍跟踪该锚片所在的一面，因此六个世界各自持续代表六个系列。
- 面上的九格当前组合由锚片所在法线确定；同一套规则同时驱动镜像 3×3 小型面板、建筑、连接线和居民目的地。
- 内部转动使用整数坐标及离散四元数/旋转矩阵记录；动画只负责平滑过渡，落点在每次转动后校正，防止长时间操作后缝隙漂移。

## 5. 六个小世界与跨界迁移

六个岛屿围绕中央魔方呈环状排布，固定在场景坐标中，不是魔方子对象。它们不会跟随 cubie、切层或自动还原而旋转；变的是镜像格面与当前组合下的局部地景参数。

每个世界拥有 9 个微型格点、地形构件、低亮度连接线、2 名小居民与一个品牌独有的整体装置。54 个能力单元在自己的格点上持续缓慢活动：轻微升降、指示片偏转或相邻连线呼吸；幅度与频率不同，但都可预测且有上界。

跨界通道固定成一条外环路径，入口门架也固定不动。居民会按节奏从一个世界迁移到相邻世界，沿真实可见的通道行走；目的世界根据两边能力组合中的连接/适配属性选择。抵达后，居民回到目的岛的本地坐标。迁徙不会带动岛屿、魔方或通道整体移动。

### 稳定演化

每次魔方转动落定后，对目标面九枚贴片计算六维属性均值与相邻格点协同性；每个世界用自己的固定权重把这些值映射成有界的地景目标。可变参数包括格点高度、连接可见度、标志性建筑尺度和居民路线优先级。目标值以缓慢插值逼近，不使用随机逐帧跳变，也不因属性增加而无限增长。

世界机制可以互不相同，底层属性仍可在异质能力相遇时形成稳定协同：例如推演+执行产生中继路线，记忆+约束维持织架，感知+连接校准观测台。即使不同品牌能力混在同一面，结果仍有明确数值来源与边界。

## 6. 归位与完满态

一个品牌面 9 枚贴片重新由该品牌能力家族占满时，该面对应的小世界进入完满态；不需要额外胜利界面。六个世界各自有不同的变化：中继线闭合、织架张开、观测环对齐、窄流汇入静池、模块集市合成庭院、工坊桁架锁定。变化由低亮度几何结构完成，不使用爆闪、全屏庆祝、粒子喷泉或文字提示。

角落还原入口会反向播放尚未归位的操作历史；它不直接把对象瞬移到初始状态。自动循环完成一轮“打乱—逆序缓慢还原”后，会丢弃已归位的自动记录，避免历史无限堆积。一次真实的手动扭层会中止正在排队的自动步骤；当前层会收束，然后由手动操作接管。用户暂停交互一段时间后，自动循环会从当前排列开始新的可逆周期。

## 7. 画面取舍与彩蛋

整体以暗色哑光材质、低饱和色带和小面积暖色金属为主。无外链字体、图片、地面粒子、强光晕或大面积辉光后处理。贴片符号和岛屿几何均由本地程序化绘制。

唯一彩蛋是 GPT 小世界下方的一颗很小的草莓形几何体。这是对 2024 年广为传播的字符计数轶事的历史引用，不代表当前或所有模型仍会数错，也不会把失误当成厂商的固有属性。

## 8. 文件、运行与可访问范围

`index.html` 是入口，引用相对路径的 `assets/style.css` 与 `app.bundle.js`。源代码位于 `src/`，构建脚本在 `tools/`，离线逻辑测试在 `tests/`。构建期使用 npm 包，交付的运行时 bundle 含 Three.js，不从 CDN 加载。现代浏览器需支持 WebGL2；不支持时会给出兼容性说明。
