# 如果明天我会离开 · 副歌 MV

一首 Suno v6 生成的中文说唱民谣，截取第一段副歌（连同前面一小节和后面的口琴间奏），做成约 47 秒的 MV。
它是一个**实时渲染的网页**，不是视频文件：每一帧都在浏览器里用 WebGL 和 Canvas 现画，画面和逐字歌词都跟着音乐走。

**打开 `index.html`，点播放。** 双击用 `file://` 打开可以，放到任何静态服务器上也可以。播放时不需要联网。
横屏、竖屏会根据窗口自动选择，也可以按 `L` 或点控制条上的按钮切换。

| 按键 | 作用 |
| --- | --- |
| 空格 / 点画面 | 播放 / 暂停 |
| ← → | 后退 / 前进 5 秒 |
| L | 横屏 ↔ 竖屏 |
| F | 全屏 |
| H | 隐藏控制条 |

## 片段

时间都是整首歌里的时间（全曲 4:02.79）。

| 时间 | 内容 |
| --- | --- |
| 46.49 | 片段开始：副歌前一小节的小节线。用一整小节（2.61 秒）淡入 |
| 46.70 – 51.60 | 主歌一最后两句（奋力拥抱在一起… / 天亮后不辞而别…） |
| 51.92 – 83.64 | 副歌八句 |
| 83.76 – 93.10 | 口琴间奏；最后 3.4 秒淡出，在主歌二的「只」（约 93.25）进来之前结束 |

速度约 92 BPM（一拍 0.652 秒）。音频的淡入、淡出直接做进 `assets/chorus.m4a`，画面的淡入淡出使用同一条增益曲线。

## 画面

前后是播放器，中间让封面活过来。

- **播放器**（开头、口琴段）：封面卡片、标题、频谱小柱、进度条、按钮，右边是逐字滚动的歌词列。
  进度条显示的是整首歌里的真实时间。口琴段的三个点按间奏进度逐个亮起。
- **进入副歌**：封面卡片无缝放大到全屏，播放器收成底部的迷你播放条（缩略图像唱片一样转）。
- **副歌八句，每句一个镜头**。镜头沿一条连续的样条曲线运动，不会一停一顿；字幕按逐字时间从虚焦中浮起来：

| 句 | 镜头 | 字幕和特效 |
| --- | --- | --- |
| 1 如果明天我会离开 / 没有任何原因 | 从全景缓慢推近旅人 | 左下 |
| 2 你能看到我的眼睛 / 看不见我的心 | 贴近他的头和琴颈；唱到「看不见我的心」时焦点越过他落到远山 | 第二行随焦点一起变虚 |
| 3 别问我要去何处 / 为了寻找何物 | 转向他要去的方向：太阳、远处的路，他只剩画面右边的背影 | 光束最强 |
| 4 当我放下所有包袱 / 也就不会再哭 | 从路面升起，雾气从地面向上飘 | 「包袱」两个字先沉一下再浮起，整句上飘 |
| 5 我不知道下一站的旅程 / 会在哪里出现 | 沿公路冲向消失点 | 一条发光的虚线从他脚下画到消失点，每一拍点亮一个站，终点是「？」；字从消失点飞出来 |
| 6 如果你有思念 / 就把它送给大雁 | 抬头看天 | 一行大雁飞过；唱完「思念」后，这两个字飞起来追上雁群 |
| 7 别问我是否疲惫 / 就这样喝醉 | 画面每两拍摇一次 | 重影、色散，字也跟着晃 |
| 8 留下我最后的爱 / 是你看不到的泪 | 贴近，再慢慢拉远 | 一滴光从镜头上滑下来，落在「泪」字上，荡开一圈涟漪 |

- **口琴段**：镜头拉到最远，然后画面缩回封面卡片，回到播放器，淡出。

### 封面是怎么动起来的

封面是一张 1024×1024 的 AI 图（黄昏公路上背吉他的旅人）。为了让镜头能真正在里面移动，先把它拆成两层：

1. **深度**（`tools/depth.py`）：Depth Anything V2（base，ONNX，CPU 运行），做水平翻转和两种分辨率的测试时增强，再用原图引导做保边平滑。
2. **人物遮罩**（`tools/layers.py`）：先按深度找出比身后路面明显更近的区域，再用 GrabCut 按颜色修边。鞋子和路面深度相同，所以把腿下方单独标成「可能是人」。轮廓先平滑去掉台阶，再羽化。
3. **背景板**：把人物从图里抹掉。这里的背景基本是横向条带（地平线、山脊、云海、路面），而镜头只会露出人物边缘的一窄条，所以每一行按左右两侧的颜色插值，再加回颗粒。
   试过 ShiftMap 和 FSR 两种纹理合成修补：前者把太阳复制进了人形区域，后者出现色块。
4. **人物颜色外渗**：人物层轮廓外的颜色全部取自人物内部，避免半透明边缘带着原位置的天空色。

着色器（`src/scene.js`）里：

- 背景按每个像素的深度反解视差和推拉；
- 人物当作一块近似刚性的平面，深度只随高度变化（肩部 0.62，到脚部 0.82，由深度图实测拟合）。如果深度在人物轮廓上有起伏，反解会在边缘折叠，画出一圈幽灵描边；
- 再加景深（按当前放大倍数换算成真实的 mip 级别）、运动模糊、山谷云海里流动的雾、路面反光、人物迎光侧的轮廓光；
- 第二个通道做泪滴折射和涟漪、色散重影、从太阳射出的光束、镜头光晕、漏光、调色、暗角和颗粒。

调试用：`index.html?debug=1` 只显示背景层，`debug=2` 只显示人物颜色，`debug=3` 只显示人物透明度。

## 歌词对齐

- **歌词原文**：副歌按你提供的汉字原样显示。主歌一、主歌二的几句由 Suno 提示词里的拼音转写而来。
- **逐字时间**：用 faster-whisper 做强制对齐（把已知文字交给 Whisper 的对齐头，只求时间，不让它猜字）。small 和 large-v3 两个模型分别对齐，大部分字的结果相差不到 0.15 秒，最终采用 large-v3。
  然后在频谱图上逐字核对了每个字的起音（`tools/align.py`，结果在 `tools/align_large-v3.json`）。
- **Suno 自带的对齐**（`hoot_cer` 0.27）在这一段整体错位：它把 51–83 秒标成了主歌一的「站在不同的街道…」，所以没有使用。
- **带歌词提示的直接识别**：large-v3 会重复编造副歌句子，所以只用强制对齐。

## 重建

需要 Python 3（numpy、librosa、faster-whisper、onnxruntime、opencv-contrib-python-headless、Pillow、fonttools、brotli）、ffmpeg、Node。

```bash
tools/cut_audio.sh /path/to/full-song.mov          # 截取片段并淡入淡出 -> assets/chorus.*, tools/clip.wav
python3 tools/align.py /path/to/full-song.mov      # 强制对齐 -> tools/align_*.json（可跳过，结果已提交）
python3 tools/build_data.py                        # -> src/data.js
python3 tools/depth.py /path/to/depth-anything-v2-base/model.onnx   # -> assets/cover-depth.png
python3 tools/layers.py                            # -> 人物遮罩、背景板、背景深度、人物颜色
python3 tools/build_images.py                      # -> src/images.js
(cd tools && npm install) && python3 tools/make_fonts.py            # -> assets/fonts.css
```

导出视频或检查画面（Playwright + 无头 Chromium，从 `file://` 打开页面逐帧渲染，和实时播放的画面完全一致）：

```bash
node tools/render.mjs video landscape 30     # -> tools/out/ruguo-mingtian-mv-landscape.mp4
node tools/render.mjs video portrait 30
node tools/render.mjs sheet landscape 30     # 联系表
node tools/render.mjs stills portrait 9 30.5 # 指定时刻的截图（片段内秒数）
```

歌名用的是副歌第一句；如果这首歌另有名字，改 `tools/build_data.py` 里的 `SONG["title"]` 再运行一次 `build_data.py` 和 `make_fonts.py` 即可。
